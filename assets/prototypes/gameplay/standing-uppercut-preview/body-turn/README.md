# Апперкот из стойки: участие корпуса и головы

Превью от 26 ноября 2026. Автор отверг `source-arm`: сохранённые пиксели руки не помогли, поскольку неподвижные корпус и голова делали контакт неестественным. Новое требование — небольшой согласованный поворот корпуса и головы. Позднее автор выбрал движение варианта 3, но отверг палитру одежды контактного кадра. Подготовлено отдельное [согласование цветов с исходной стойкой](../color-match/README.md). В игру серия не интегрирована.

Три цельных ключевых рисунка:

1. **Доворот плеча:** компактный контакт, поворачиваются плечевой пояс и голова, обе стопы остаются на земле.
2. **Перенос веса:** грудь раскрывается сильнее, передняя нога принимает вес, задняя слегка разворачивается. Вариант заметно отличается разворотом плеч от 1/3; это наиболее выраженная трактовка поворота в серии.
3. **Восходящий:** корпус немного распрямляется, задняя пятка приподнимается, кулак выше. Голова следует за плечами, взгляд направлен вправо.

Это выбор **целой контактной позы**, а не окончательная многокадровая анимация: исходная стойка 600 мс → новый контакт 140 мс → исходная стойка 860 мс. Два разных рисунка на вариант, быстрый непосредственный возврат. Замедление умножает времена на четыре. Подготовка, игровые окна, BB и физика не менялись.

## Источники и производство

Встроенный `image_gen`: три новые цельные позы по оригинальному `boxer-0.webp` (зарегистрированный `../frames/idle.png`) и утверждённому `boxer-13.webp` как примеру поворота и штриховки. Промпты — `prompts.json`. Рисунки полностью сгенерированы, не получены вращением отдельных костей; попиксельное сохранение лица и одежды не обещается. Числа углов/суставов в промптах — пожелания, не измеренный результат.

Вторая версия 2 исправляет обнаруженный при отсмотре поднятый подбородок. Исходная попытка сохранена как `inputs/b-transfer-v1.png`, уточнение — `revision-prompt.json`. Основной референс при исправлении снова исходный idle, предыдущая генерация не единственный эталон. Поворот груди у 2 всё равно сильнее, чем у 1/3; это видно в готовом сравнении.

`export.py` однократно уменьшает весь исходный холст до 500×550 без изменения соотношения сторон, затем смещает его по вручную выбранной регистрации передней подошвы. Нет нормализации по высоте кулака и растяжения руки. Смещения и хеши — `verification.json`. Оригинальные ноги не подклеиваются поверх: поворот таза/опор остаётся частью каждого цельного рисунка. Новые складки, обувь и положение головы могут отличаться от idle; это самостоятельные арт-пробы для оценки, не доказанная консистентная замена игровых спрайтов.

## Отсмотр и проверки

Агент просмотрел источники, контактный лист декодированного GIF, воспроизведение сравнения в Chrome и снимки обоих состояний. Видно изменение корпуса/головы и опор; нет замороженного лица на отдельно вращающейся руке. Наиболее компактный 1, самый раскрытый 2, наиболее выраженный подъём 3. Дискретность перехода сохранена намеренно для выбора ключевых поз. Художественная естественность и соответствие ожидаемому стилю остаются оценкой автора.

```bash
python3 assets/prototypes/gameplay/standing-uppercut-preview/body-turn/export.py
python3 -m unittest discover -s assets/prototypes/gameplay/standing-uppercut-preview/body-turn -p test_export.py
npm --prefix scene-lab run typecheck
npm --prefix scene-lab run lint
```

Четыре автоматические проверки проходят: некорректные/пустые/обрезанные входы, размеры/прозрачность/область передней подошвы, изменения непустых областей головы и корпуса, все 8 GIF с длительностями/замыканием/отличным контактом, неверные аргументы кодировщика. Пиксельное отличие головы не доказывает правильный поворот; это отдельно оценено глазами. Typecheck и lint приложения проходят. Browser smoke подтверждает два воспроизводимых рисунка сравнения, не качество анатомии.

Публичные результаты — `scene-lab/public/previews/standing-uppercut/body-turn/`: `comparison.gif`, `comparison-slow.gif`, отдельные варианты и `decoded-sheet.png`. Исходники и итоговые кадры сохранены рядом с этим файлом.
