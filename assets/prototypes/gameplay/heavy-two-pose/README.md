# Сильный удар: три альтернативы из двух рисунков

Запрос автора 24.11.2026: отказаться от неудачных промежуточных поз правого бокового; показать три варианта **idle → контакт**. Только предпросмотр, в игру не интегрированы. Одобрение нового варианта пока не получено.

1. **Боковой в голову** — ранее утверждённый контакт левого бокового v2, без изменения рисунка. Высокий локоть, поворот таза и задней стопы.
2. **Рубящий сверху** — высокая линия плеча и диагональ предплечья вниз; корпус подаётся за кулаком. По назначению пересекается с существующим `↑ + K`, если впоследствии выбирать его для обычного тяжёлого удара.
3. **Силовой в корпус** — более низкая стойка, согнутый локоть и вращение корпуса; видимая линия контакта ниже, чем у двух других.

Каждая анимация содержит ровно **два уникальных рисунка**. Последовательность GIF: idle 550 мс → контакт 120 мс → исходный idle 540 мс. Последняя стойка — тот же рисунок, а не третий кадр. Нет морфинга, интерполяции или промежуточных поз. Замедленные копии ×4 нужны для отсмотра рисунков; это не игровые тайминги. Длительность idle включает паузу между повторениями, а не предложение о startup игры.

Одна арена, исходный runtime scale 1.19, один origin (228,495) и общий передний носок (344,485) на native-холсте 500×530. Удар в корпус намеренно ниже; высоты новых фигур выбраны вручную, не извлечены из видео. `registration.json` сохраняет преобразования.

Лицо и волосы двух новых контактов собраны из исходных пикселей idle; оригинальная стойка и утверждённый левый контакт сохранены целиком. Тело новых поз нарисовано встроенным `image_gen` по исходному idle и утверждённому контакту. Промпты — `prompts.json`, исходные генерации — `inputs/`. Это новые черновики корпуса: совпадение исходных пикселей лица не доказывает художественное утверждение всего рисунка.

Проверен контакт из **декодированного GIF** и исходная стойка на контактном листе: три разных положения руки/корпуса, полностью видимые стопы, отсутствие прежнего высокого воротника. Варианты остаются намеренно дискретными. Решение о том, какой из них ощущается достаточно тяжёлым, остаётся за автором.

Результаты: `scene-lab/public/previews/heavy-two-pose/` — comparison.gif, три отдельных GIF, замедленные копии и contact-sheet.png. Одна общая палитра; автоматическая проверка сопоставляет каждую отдельную анимацию с её панелью сравнения.

Воспроизведение из корня проекта:

```sh
node assets/prototypes/gameplay/heavy-two-pose/build.mjs
python3 assets/prototypes/gameplay/heavy-two-pose/export.py
python3 assets/prototypes/gameplay/heavy-two-pose/validate.py
```

Нужны установленные зависимости `scene-lab` (Playwright), `/usr/bin/google-chrome`, Pillow и DejaVu Sans. Геометрия попаданий, управление и игровой код не менялись. Откат предпросмотра — удаление только новой папки исходников и `public/previews/heavy-two-pose`.
