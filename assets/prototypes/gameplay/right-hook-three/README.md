# Правый боковой: три двухкадровых альтернативы

24.11.2026 автор подтвердил левый боковой и отверг правый из `heavy-two-pose`. Запрос: три новых правых на выбор. Левый остаётся без изменений. Новые варианты не утверждены и не интегрированы в боёвку.

| Вариант | Видимый акцент |
| --- | --- |
| А. Короткий | Сильное перспективное сокращение плеча, компактный кулак перед головой, вертикальная кисть |
| Б. Широкий | Более заметная спина, развёрнутое плечо, предплечье поперёк верхней части корпуса, кисть ладонью вниз |
| В. Длинный | Более открытый локоть, большая дальность, наклон корпуса к цели, вертикальная кисть |

Во всех вариантах бьёт ближняя правая рука, дальняя остаётся у челюсти. Это самостоятельные контактные рисунки, не зеркальные копии левого. В отвергнутом варианте локоть был низким, а запястье согнутым вниз; новые рисунки показывают более высокую горизонтальную линию удара и выровненную кисть. Проекция сгиба локтя в А/Б сокращена перспективой, поэтому по одному силуэту нельзя доказать анатомический угол в пространстве. Это варианты художественной позы, не восстановление спортивной съёмки.

Одинаковый режим: **idle 550 мс → контакт 120 мс → тот же idle 540 мс**. Ровно два уникальных рисунка, без промежуточных поз, морфинга или эффектов. Время idle включает паузу между повторениями и не задаёт startup игры. Замедленные копии — ×4.

Единый native-холст 500×530, origin (228,495), scale 1.19, носок передней стопы (344,485). Полные генерации — `inputs/`; встроенный image_gen использовал оригинальную стойку и выбранный левый как общие референсы. Полные промпты — `prompts.json`. Стойка скопирована из оригинала, лицо и волосы каждого контакта собраны из её пикселей с ручными offsets из `poses.json`. Новые корпус/руки/ноги остаются авторскими черновиками генератора; совпадение лица не означает утверждения остального рисунка.

Просмотрены исходные контакты, нормализованные фигуры и контакт из декодированного сравнительного GIF: более высокий локоть относительно отвергнутого варианта, три разных дистанции/поворота, без прежнего высокого воротника. Возврат в исходную стойку намеренно мгновенный, согласно двухкадровому формату. Окончательная оценка естественности и выразительности остаётся за автором.

Результаты в `scene-lab/public/previews/right-hook-three/`: comparison.gif, comparison-slow.gif, a/b/c.gif, их slow-копии и contact-sheet.png. Все GIF используют общую палитру; отдельные версии попиксельно совпадают со своими панелями сравнения. `verification.json` содержит длительности и хеши.

Воспроизведение из корня репозитория:

```sh
node assets/prototypes/gameplay/right-hook-three/build.mjs
python3 assets/prototypes/gameplay/right-hook-three/export.py
python3 assets/prototypes/gameplay/right-hook-three/validate.py
```

Зависимости: Playwright из `scene-lab`, `/usr/bin/google-chrome`, Pillow, DejaVu Sans. Тесты проверяют сохранность выбранного левого и исходного idle, размеры/альфу/стопы, реальные исходные пиксели лица, ровно два рисунка, времена, луп и соответствие отдельных GIF панелям. Поведение игры и hit/hurt BB не менялись.
