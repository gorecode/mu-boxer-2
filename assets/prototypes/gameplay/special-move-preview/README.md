# Два спецприёма: предпросмотр V2 без новых рисунков

Черновая постановка для оценки автором. Игровая модель, управление, баланс и runtime-ассеты не изменены. Рабочий следует заданной последовательности; попадания, урон, толчок и уклонение в игре пока не реализованы для этих спецприёмов.

Авторские правки после V1:

- Таранный прямой почти сразу вытягивает руку, скользит с активным ударом и отталкивает противника.
- Вместо оттяжки с одним боковым: короткий прыжок назад и сразу двойка — боковой в голову, затем быстрый прямой другой рукой.
- Третий вариант, нырок в корпус, отвергнут. Удалён из текущей сборки и публичных GIF; предыдущая версия остаётся в истории Git.

## Постановка

**Таранный прямой.** На 600 мс начинается выход руки через готовый промежуточный рисунок. Через 40 мс уже показан исходный контакт `boxer-2`; он сохраняется на всём скольжении. До цели герой проходит 250 игровых пикселей за 260 мс. С 900 до 1240 мс оба персонажа синхронно продвигаются ещё на 190 px: дистанция между их origin остаётся 290 px. Активная фаза 640–1240 мс, один контакт/снятие здоровья на противника, непрерывный толчок после попадания; многократный урон по одной цели не подразумевается. Визуальная отметка контакта длится 60 мс. Рука возвращается в стойку на 1300 мс.

**Отскок → двойка.** Прыжок назад на 190 px длится 160 мс, root движется по дуге высотой 55 px. После приземления без паузы начинается ответный шаг на 350 px за 160 мс. Боковой — утверждённый левый `boxer-12`, контакт 960–1040 мс. Затем 40 мс смены руки через готовый `cross-hybrid/cross-0`, прямой другой рукой — исходная поза второго лёгкого `boxer-3`, контакт 1120–1240 мс. Между началами попаданий 160 мс. Первый удар отталкивает на 20 px, второй — ещё на 80 px. После прыжка ГГ атакует с земли.

Цикл 2600 мс; `-slow.gif` содержит те же кадры в 4 раза медленнее. Затемнение в конце сбрасывает демонстрацию. Все целые рисунки взяты из `scene-lab/public/art/fight/`, anchors и scale — из manifest. Руки не растягивались, части тела не переставлялись. Шлейф и отметка контакта процедурные. Палитра общая для обоих вариантов.

## Воспроизведение и проверки

Из корня репозитория, с установленными зависимостями `scene-lab`, Chrome и Pillow:

```bash
node assets/prototypes/gameplay/special-move-preview/build.mjs
python3 assets/prototypes/gameplay/special-move-preview/export.py
```

`source-manifest.json` фиксирует хеши исходников, `timeline.json` — позы, координаты, высоту прыжка, активность и окна контакта. Промежуточные PNG исключены из Git. Публичные результаты: `scene-lab/public/previews/special-move-preview/`.

Экспорт проверяет исходники, размеры, замкнутый цикл, исходную регистрацию, выход руки за 40 мс, активную позу на всём скольжении, синхронный толчок, полёт/приземление, разные руки и два разделённых окна попадания, отсутствие контактов на возврате. Декодированные обычные и замедленные GIF обязаны совпадать покадрово и иметь правильную длительность.

Самопроверка V2: просмотрена хронологическая последовательность декодированных кадров обоих GIF. У прямого рука вытягивается до начала скольжения и сохраняет позу при толчке. Во втором варианте виден отрыв ног от земли, промах лопаты, приземление, затем две разные контактные позы. После первого отсмотра увеличен отход и скорректирован момент тычка, чтобы лопата не пересекала голову на прыжке. Компактная существующая поза прыжка и длинный ответный шаг остаются ограничениями черновика. Экспортные проверки, синтаксис сборщиков, typecheck и lint прошли; полный набор тестов боя не запускался, runtime не изменён.

Старые V1 не считались утверждёнными. Новая постановка также требует авторской оценки; GIF не доказывает работоспособность будущих хитбоксов или баланса.
