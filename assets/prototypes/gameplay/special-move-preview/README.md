# Два спецприёма: предпросмотр V3 без новых рисунков

Черновая постановка для оценки автором. Игровая модель, управление, баланс и runtime-ассеты не изменены. Рабочий следует заданной последовательности; попадания, урон, толчок и уклонение в игре пока не реализованы для этих спецприёмов.

Последние авторские правки:

- После первого контакта таранного прямого сразу следует второй удар другой рукой; ранний выход руки и скольжение сохранены.
- В двойке после отскока удары поменяны местами: сначала прямой, затем боковой в голову другой рукой.
- Третий вариант, нырок в корпус, отвергнут. Удалён из текущей сборки и публичных GIF; предыдущая версия остаётся в истории Git.

## Постановка

**Таранный прямой.** На 600 мс начинается выход руки через готовый промежуточный рисунок. Через 40 мс уже показан исходный контакт `boxer-2`; до цели герой скользит с вытянутой рукой на 250 игровых пикселей за 260 мс. Первый контакт 900–960 мс. Сразу после него 40 мс смены руки через `cross-hybrid/cross-0`, второй прямой `boxer-3` с контактом 1000–1120 мс. Между началами попаданий 100 мс. Во время смены руки нет активной зоны. Толчок противника на 190 px продолжается с 900 до 1240 мс; герой добавляет 27 px входа при смене руки, чтобы более короткий рисунок второго прямого сохранил контакт. Активность второго удара заканчивается на 1240 мс, стойка показана с 1300 мс. Два отдельных попадания, без повторного урона на каждом кадре скольжения.

**Отскок → двойка.** Прыжок назад на 190 px длится 160 мс, root движется по дуге высотой 55 px. После приземления без паузы начинается ответный шаг на 270 px за 160 мс. Первым идёт прямой другой рукой `boxer-3`, контакт 960–1040 мс. Затем 40 мс возврата этой руки через готовый `cross-hybrid/cross-0`, вторым — утверждённый левый боковой `boxer-12`, контакт 1120–1240 мс. Между началами попаданий 160 мс. Герой добавляет 100 px входа для более короткого бокового: origin первого контакта700, второго800. Первый удар отталкивает на 20 px, второй — ещё на 80 px. В начале второго контакта показана исходная поза Рабочего, затем реакция; так боковой не проходит перед уже отклонённой головой. После прыжка ГГ атакует с земли.

Цикл 2600 мс; `-slow.gif` содержит те же кадры в 4 раза медленнее. Затемнение в конце сбрасывает демонстрацию. Все целые рисунки взяты из `scene-lab/public/art/fight/`, anchors и scale — из manifest. Руки не растягивались, части тела не переставлялись. Шлейф и отметка контакта процедурные. Палитра общая для обоих вариантов.

## Воспроизведение и проверки

Из корня репозитория, с установленными зависимостями `scene-lab`, Chrome и Pillow:

```bash
node assets/prototypes/gameplay/special-move-preview/build.mjs
python3 assets/prototypes/gameplay/special-move-preview/export.py
```

`source-manifest.json` фиксирует хеши исходников, `timeline.json` — позы, координаты, высоту прыжка, активность и окна контакта. Промежуточные PNG исключены из Git. Публичные результаты: `scene-lab/public/previews/special-move-preview/`.

Экспорт проверяет исходники, размеры, замкнутый цикл, исходную регистрацию, выход руки за 40 мс, активную позу на всём скольжении, синхронный толчок, полёт/приземление, разные руки и два разделённых окна попадания, отсутствие контактов на возврате. Декодированные обычные и замедленные GIF обязаны совпадать покадрово и иметь правильную длительность.

В V3 перемещение подогнано под разную дальность исходных рисунков прямого и бокового, руки не удлинялись. Просмотрена хронологическая последовательность декодированных GIF: ранний выход руки, первый контакт, смена руки, второй контакт и возврат. Проверки порядка рук, обоих окон контакта, дополнительного входа, границ активности, нормальных/замедленных GIF и замкнутого цикла прошли. Синтаксис сборщиков, typecheck и lint также прошли. Полный набор тестов боя не запускался: игровой runtime не изменён. Новую последовательность нужно оценить автору.

Старые V1 не считались утверждёнными. Новая постановка также требует авторской оценки; GIF не доказывает работоспособность будущих хитбоксов или баланса.
