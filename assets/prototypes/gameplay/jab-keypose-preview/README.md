# Джеб: исходные ключевые позы и два промежуточных рисунка

Автор отверг 18-кадровое движение после проверки в игре: плавно, но неестественно, теряется дух Comix Zone. Этот эксперимент сохраняет исходную стойку `boxer-0.webp` и исходную полнотелую контактную позу `boxer-2.webp`. Из нового листа взяты только `jab-2.webp` и `jab-12.webp`, без дорисовки, смешивания и изменения их анатомии.

| Время приёма | Рисунок | Назначение |
| --- | --- | --- |
| 0–40 мс | Исходная стойка | Подготовка |
| 40–80 мс | Новый кадр 2 | Один промежуточный выход |
| 80–160 мс | Исходная контактная поза | Удар и выдержка |
| 160–180 мс | Новый кадр 12 | Один промежуточный возврат |
| 180–340 мс | Исходная стойка | Возврат завершён, приём ещё восстанавливается |

Четыре разных рисунка, два из них добавлены. В исходной контактной позе работают плечи и корпус; новый непрерывный риг руки не проигрывается. Соотношение фаз 80/80/180 мс сохранено для сравнения. По просьбе автора промежуточный возврат сокращён с 60 до 20 мс: idle теперь с 180 мс вместо 220 мс. Начало и конец совпадают со стойкой. Правки боевого кода, BB и управления не внесены; при внедрении нужен аудит BB под исходный кулак (около 255 px вместо 248 у рига).

`hybrid.webp` — анимация; `comparison.webp` — синхронно исходные две позы / текущие 18 кадров / гибрид. GIF 1× и ¼× лежат в `.capture/`. `contact-comparison.png` показывает рисунки без GIF-квантизации. Отсмотр агента не является утверждением автора.

## Воспроизведение

После сборки игры с работающим preview на 4197:

```sh
node --test assets/prototypes/gameplay/jab-keypose-preview/schedule.test.mjs
node assets/prototypes/gameplay/jab-keypose-preview/capture.mjs
python3 assets/prototypes/gameplay/jab-keypose-preview/export.py
```

`capture.mjs [URL]` использует реальные часы джеба и общий Canvas игры, временно подставляя выбранные исходные рисунки. Это визуальный предпросмотр; модель боя не меняется. Скрипт проверяет реальные вызовы рисования, исходный контакт и ровно два добавленных кадра. Экспорт декодирует GIF, проверяет длительность и замыкание. 61 снимок с шагом 20 мс включает паузу до/после удара: 1220 мс на луп.
